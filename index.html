내 신청서 양식 만들기

가지고 있는 신청서·계약서 양식을 PDF로 올리면, 원본 모양 그대로 입력할 수 있는 양식으로 만들어 줍니다.

  1. PDF 올리기 – 입력칸을 자동으로 찾아 줍니다.
  2. 칸 편집 – 칸을 끌어 옮기거나 크기를 바꾸고, 빈 곳을 드래그해 새 칸을 그립니다. 칸마다 종류(글자·체크·날짜·서명·선택 목록)를 정합니다.
  3. 작성 – 입력·서명하고 인쇄하거나 PDF로 저장합니다. 작성 내용은 파일로 저장해 두고 다시 열 수 있습니다.
  4. 공유 – ‘양식 파일로 내보내기’로 받은 파일을 다른 사람이 ‘양식·작성 파일 열기’로 가져오면 같은 양식을 바로 쓸 수 있습니다.

PDF나 양식 파일을 이 화면에 끌어다 놓아도 됩니다.
글자가 선택되는 PDF는 칸을 자동으로 찾고, 스캔한 PDF는 칸을 직접 그려야 합니다.
개인정보가 들어 있지 않은 빈 서식을 올려 주세요.

사용법

📝 작성하기

  • 칸을 클릭해서 바로 입력합니다. 초록 칸은 두 양식에 동시에 들어가고, 파란 칸은 그 양식에만 들어갑니다.
  • 수급자와의 관계를 본인으로 고르면 신청인 성명·전화번호·주소가 수급자 칸에 자동으로 들어갑니다.
  • 수급자 주소를 넣으면 ‘○○군수 귀하’ 같은 단체장 명칭이 자동으로 바뀝니다.
  • ✍ 서명 칸을 누르면 그 부분이 화면 가득 확대됩니다. 점선 칸 안에 손가락·펜(휴대폰·태블릿)이나 마우스로 서명하고 ✔ 서명 넣기를 누르면 원래 크기로 줄어들며 제자리에 들어갑니다. 🔴 도장 이미지로 도장 사진을 찍을 수도 있습니다(흰 배경은 자동으로 지워짐). 다시 누르면 고쳐 쓰거나 삭제할 수 있고, 서명은 저장 파일에도 함께 저장됩니다.
  • 복지용구 대여기간 칸을 누르면 달력이 뜹니다. ‘아래 줄도 모두 같은 기간으로 입력’을 체크하면 그 아래 줄에 한 번에 들어갑니다.
  • 날짜 옆 ☑오늘을 체크하면 오늘 날짜가 들어갑니다(인쇄에는 안 나옵니다).
  • 상단 장기요양기관 목록에서 기관을 고르면 희망기관과 이용희망기관이 한 번에 채워집니다. 기관은 ⚙ 기관 관리에서 등록합니다.

💾 신청서를 파일로 저장하기 (한 명당 파일 하나)

  1. 작성을 마치면 💾 이 신청서 저장을 누릅니다.
  2. 크롬·엣지에서는 저장 위치를 고르는 창이 뜹니다. 보관할 폴더(예: 문서\장기요양 신청서)를 골라 저장하세요.
    그 외 브라우저에서는 ‘다운로드’ 폴더에 저장됩니다.
  3. 파일 이름은 입소이용신청서_수급자이름_신청일.json으로 자동으로 정해집니다. 필요하면 바꿔도 됩니다.
저장한 파일에는 두 양식(입소·이용신청서, 재가서비스 이용내역서)의 입력 내용이 모두 들어 있습니다.
저장할 때 날짜는 그날 날짜로 고정되어, 나중에 열어도 ‘오늘’로 바뀌지 않습니다.

📂 저장한 신청서 다시 불러오기

  • 📂 저장한 신청서 열기를 눌러 .json 파일을 고르거나, 파일을 이 화면 위로 끌어다 놓으면 됩니다.
  • 불러온 뒤 필요한 부분만 고쳐서 다시 인쇄하거나, 갱신·변경 신청에 그대로 활용하세요.
    고친 내용을 남기려면 다시 💾 이 신청서 저장을 누르세요(같은 이름으로 덮어쓰거나 새 이름으로 저장).
  • 지금 화면에 작성 중인 내용이 있으면 불러오기 전에 한 번 더 확인합니다.

🧩 직접 만든 양식

  • 오른쪽 4. 직접 만든 양식 → ＋ 새 양식 만들기에서 PDF를 올리면 원본 그대로 입력 양식이 만들어집니다.
  • 🛠 칸 편집에서 칸을 고치고, ✏️ 작성에서 입력·서명·인쇄합니다. 이름이 같은 칸은 함께 입력됩니다.
  • 여러 칸 묶기: 칸 편집에서 Ctrl(또는 Shift)+클릭으로 여러 칸을 고르거나(쪽이 달라도 됨), Shift+빈 곳 드래그로 영역을 잡은 뒤 🔗 같은 이름으로 묶기를 누르면 한 곳에 입력할 때 모두 채워집니다. 휴대폰·태블릿은 ☐ 여러 칸 선택을 켜고 누르세요.
  • 날짜: ‘  년  월  일’ 자리는 자동으로 날짜 칸 하나로 합쳐지고 원래 ‘년·월·일’ 글자는 가려집니다. 작성할 때 칸을 누르면 달력이 뜨고 한 번에 입력되며(예: 2026년 10월 2일), ☑오늘을 체크하면 오늘 날짜가 들어갑니다(인쇄·PDF에는 안 나옴). 날짜 모양은 칸 편집에서 바꿀 수 있습니다. 직접 합치려면 칸 여러 개를 골라 📅 날짜 칸 하나로 합치기를 누르세요.
  • 기간: 날짜 칸 바로 옆에 또 날짜 칸이 있으면 ‘기간’으로 인식합니다. 두 번째(끝) 날짜를 누르면 오늘·1개월·3개월·6개월·1년·2년·달력 입력이 나와, 시작일 기준으로 끝 날짜가 자동 계산됩니다(예: 10월 2일부터 1개월 → 11월 1일). 시작일을 바꾸면 끝 날짜도 따라 바뀝니다.
  • 💬 입력 도움말: 칸 편집에서 칸을 고르고 ‘입력 도움말’을 적어 두면, 작성할 때 그 칸을 누르거나 마우스를 올릴 때 칸 위에 작은 풍선으로 뜹니다. 도움말이 있는 칸은 오른쪽 위에 주황 점이 보이며, 인쇄·PDF에는 나오지 않습니다.
  • 원래 글자 가리기: 칸 편집에서 원래 글자 위에 칸을 그리면 그 글자는 자동으로 가려지고 그 자리에 입력합니다(칸 속성의 ‘원래 글자 가리기’로 끄고 켬). ▭ 가림 상자 그리기를 켜고 그리면 입력 없이 원래 내용만 지우는 흰 상자가 됩니다.
  • (서명 또는 인)·(인)·(서명)·(날인) 자리는 자동으로 서명 칸이 되고, 누르면 화면 전체 서명판이 열립니다.
  • 양식 파일로 내보내기로 받은 파일을 보내 주면, 다른 사람도 ‘양식·작성 파일 열기’로 같은 양식을 쓸 수 있습니다.

📊 제출 PDF 모아 엑셀로 (담당자용)

  • 오른쪽 6. 제출 PDF 모아 엑셀로에서 원래 서식을 고르고, 신청인들이 이 도구모음으로 작성·서명해 PDF로 저장한 파일들을 한꺼번에 올립니다.
  • 한 사람(파일)당 한 줄로 입력 내용이 정리되고, 📊 엑셀 파일로 받기로 .xlsx 파일을 받습니다. 서명은 ‘있음/없음’으로만 표시됩니다.
  • 이 도구모음으로 만든 PDF에는 작성 내용이 보이지 않는 작은 글자로 함께 들어 있어 정확히 읽습니다. 그 정보가 없는 PDF는 입력칸 위치의 글자를 읽습니다(인쇄 배율·여백을 바꿔 저장했거나 스캔한 PDF는 읽지 못할 수 있음).
  • 올린 PDF는 이 컴퓨터 안에서만 읽고 어디에도 보내지 않습니다.

🖨 인쇄 · PDF

  • 이 양식 인쇄/PDF 또는 두 양식 함께 인쇄/PDF를 누르고, 인쇄 창에서 대상을 ‘PDF로 저장’으로 고릅니다.
  • 여백 ‘없음’, 배율 ‘기본(100%)’, 머리글/바닥글 끄기로 설정하면 원본 서식과 똑같이 나옵니다.
  • 인쇄할 때 급여 이용 신청내용의 빈 줄은 1줄만 남기고 위로 정리됩니다.

ℹ 알아두기

  • 작성 중인 내용은 이 브라우저에 자동으로 임시 저장되어, 창을 닫았다 열어도 남아 있습니다. 다만 이것은 한 건만 보관되므로, 수급자별로 남기려면 꼭 파일로 저장하세요.
  • 새로 작성을 누르면 화면이 비워집니다(단체장 명칭과 기관 목록은 유지).
  • 저장 파일에는 주민등록번호 등 개인정보가 들어 있으니 업무용 PC의 보안 폴더에 보관하세요.
